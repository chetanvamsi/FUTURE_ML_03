# 📌 Resume Screening System (Task 3)

## 🔹 Objective

This project builds a simple system to compare resumes with a job description and rank candidates based on skill matching.

---

## 🛠️ Tools Used

* Python
* Scikit-learn
* CountVectorizer
* Cosine Similarity

---

## ⚙️ How It Works

* Resumes and job descriptions are converted into numerical vectors
* Cosine similarity is used to compare them
* Each candidate is assigned a score
* The best candidate is selected based on highest score
* Missing skills are identified

---

## ▶️ Output Example

Candidate 1 Score: 0.86
Candidate 2 Score: 0.0
Best Candidate: Candidate 1
Missing Skills: None
